# Pakete für marvin_baby

## Noch zu installieren (manuell ausführen):

```bash
sudo apt install -y \
  ros-humble-gz-ros2-control \
  ros-humble-ros2-control \
  ros-humble-ros2-controllers \
  ros-humble-mecanum-drive-controller
```

## Warum:
- ros-humble-gz-ros2-control        → Gazebo Harmonic Hardware-Interface für ros2_control (Plugin gz_ros2_control-system)
- ros-humble-ros2-control           → controller_manager (Fehler: "package 'controller_manager' not found")
- ros-humble-ros2-controllers       → joint_state_broadcaster und andere Standard-Controller
- ros-humble-mecanum-drive-controller → Controller für Mecanum-Räder (cmd_vel → 4 Rad-Velocities)
